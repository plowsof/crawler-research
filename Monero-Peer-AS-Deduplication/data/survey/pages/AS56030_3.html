Frequently Asked Questions

Find answers to commonly asked questions about our service.

To create a cloud server, we take multiple high performance physical servers and use virtualisation to create a number of 'virtual machines' on them. These are cloud servers, each possessing its own virtualised allocation of CPU, RAM, and Disk, in fact everything you would physically need to create a server. Storage space is provided by clustering all the available storage on the same physical servers your virtual machines run on in a way that the loss of any physical server does not cause a loss of data. This combination of multiple physical servers working together to provide compute and storage unlocks the High Availability and performance balancing features of Cloud Servers.

Virtual machines are automatically balanced between physical servers based on load, if a physical server becomes busy virtual machines are automatically migrated to other servers in the cluster ensuring your virtual machine maintains optimum performance.

If your virtual machine is running on the physical server at the time it fails, then you will suffer a brief outage whilst the issue is detected and your virtual machine is automatically started on another server. Alternatively if only some of your storage was provided by the server, there will be no noticeable impact to your running virtual machine, and the lost data will automatically be rebuilt on another node.

A cloud server is similar to a virtual private server (VPS) except it doesn't only exist on just one physical host, it has the ability to run across many physical hosts and storage clusters. This unlocks high availabilty failover and performance features that are typically not found on lower cost VPS plans.

Voyager Cloud leverages NVMe and SSD drives paired with high performance RDMA networking to deliver a hyperconverged storage solution with low latency that is distributed across multiple physical servers and hard drives.

Your data is stored on an encrypted, clustered storage array which spreads your data across numerous disks and multiple physical servers. Virtual machines are assigned to different storage tiers that each support different degrees of simultaneous failure without loss of service.

A major benefit to Voyager Cloud Servers is that all servers include managed backups and are automatically backed up off-site daily for 14 days.

This eliminates the need to estimate additional costs of backup storage or replication policies and provides peace of mind that your data is protected.

We still recommend that you perform your own backups for critical data, such as databases or content that changes frequently. Once a day backups may not be enough to prevent data-loss depending on your application.

By default, our Cloud Servers are provisioned to the Voyager Cloud cluster based in our Auckland Data Centre. Upon request, we can provision to our Christchurch cluster for redundancy and diversification.
