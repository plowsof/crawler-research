VPS and VDS
FAQs

What is VPS Hosting?

A Virtual Private Server (VPS) is a partitioned portion of a physical server, functioning as an independent virtual machine with dedicated resources. VPS hosting enables users to host websites and various software applications on these virtual servers, offering more power and control than shared hosting.

A VPS features its own operating system and can be separately rebooted, ensuring isolation and non-interference between different servers. While Hivelocity manages the physical servers and guarantees speed, uptime, and stability, users are responsible for managing their individual servers — creating an ideal balance of power and support.

What is a Virtual Dedicated Server (VDS)?

A Virtual Dedicated Server is a hosting solution that provides the functionality and resources of a dedicated server but in a virtualized environment. Unlike shared hosting or traditional VPS, VDS gives you fully dedicated hardware resources like CPU, RAM, and storage, ensuring even better performance and reliability.

What is the difference between VPS and VDS?

While VPS and VDS are similar, VDS offers dedicated hardware resources for each virtual server, eliminating resource sharing. VPS typically shares physical hardware among multiple servers, which can impact performance during peak usage. In short, VDS provides fully dedicated resources to each user, whereas VPS shares resources among multiple users on a single physical server.

Who should use VPS hosting? Who should use VDS?

VPS hosting offers a balance of resources and cost, making it an ideal choice for those needing more resources than shared hosting can offer but without the higher price tag of a dedicated server. It’s well suited for moderately sized web projects, developers, bloggers, and e-commerce owners.

VDS hosting is ideal for businesses, developers, and organizations that require fully dedicated resources, need better performance than shared or VPS hosting, or run resource-intensive applications and high-traffic websites.

How does VPS or VDS hosting compare to a dedicated server?

VPS and VDS hosting provide a balance between shared hosting and dedicated server hosting. Unlike shared hosting, you have greater control over your virtual space, yet you still share the physical server (though VDS dedicates hardware resources to you). Both options are more powerful than shared hosting but less expensive than a dedicated server.

A dedicated server gives you exclusive access to all resources, making it the most powerful and flexible option. If you need to manage the hardware yourself, build complex architectures, create a private network, or deploy complex non-web solutions, a dedicated server is recommended. Generally, users with a growing volume of web activity upgrade to dedicated servers for more adaptable setups that can accommodate high growth levels.

Can I install custom software on my VPS or VDS?

Yes, you have full root access to your server, which allows you to install and configure custom software as needed. Please ensure that the software is compatible with the server’s operating system and complies with our acceptable use policy. If you need assistance, our support team is here to help.

Yes, you can upgrade your hosting plan at any time. Hivelocity’s plans are designed to scale along with your needs. Whether it’s more disk space, increased CPU power, or bandwidth, you have the flexibility to start small and expand as your business or project grows. To upgrade, navigate to your account dashboard and select the “Upgrade” option. You’ll have the option to choose any higher tier plan or simply add additional disks. The process is swift and doesn’t cause any downtime.

Can I create a private network between my VPS/VDS and dedicated servers?

Absolutely. You can create a private network (VLAN) between your VPS, VDS, and dedicated servers at Hivelocity. This setup is particularly useful when you have known workloads that are more cost-effective on dedicated servers but also require small side processes or the capacity to handle bursts, which can be addressed with VPS or VDS.

Hivelocity is one of the few global providers that offer this capability, and we are the most cost-effective option for it.

Is Port 25 open?

No, Port 25 is blocked on our VPS Hosting servers. This security measure is adopted by the majority of hosting providers to prevent abuse. To send emails from your VPS, you can either use alternative ports such as 587 or 465, employ a third-party email service, or consider upgrading to one of our dedicated server solutions.
