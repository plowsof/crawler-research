Reload page Docs Cloud Servers Overview Last change on 2022-06-28 • Created on 2022-06-28 • ID: CL-45586 Primary IPs Primary IPs are public IP addresses (IPv4, IPv6) for cloud servers. Cloud servers do not have a public network interface unless at least one Primary IP is assigned to them. Both resources can be managed independently. This means that it is possible to create Primary IPs without assigning them to a cloud server. And you can create cloud servers with or without assigning public IP addresses (Primary IPs) to them. As long as the power state of existing servers is "off", you can freely add, remove or replace the Primary IPs of those servers. To assign a Primary IPv6 after the initial server creation, you need to do a basic manual configuration . Every cloud server can have a total of one Primary IP per type (IPv4, IPv6). See the getting started guide to learn how to create a Primary IP. Pricing We do not charge for our Primary IPv6s. We charge € 0.50 / $ 0.60 per month (excl. VAT) for our Primary IPv4s.
